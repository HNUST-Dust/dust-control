# CAN3 三电机 + HI91/SBUS 首轮功能检查

2026-10-30，125us，Rx208/Tx688，CAN2/IMU排除，专用I225 ASPM三个开关均0；同一 `periph_can3` 固件，OTHER调度、mlock1。主站使用独立三地址失能/零力矩台架，新增UART累计ACK及内存采集，未改从站固件。

100命令/100 RTT样本通过，超时0、WKC缺失0。RTT均值1187.012us、P95 1373.325us、最大1498.233us，仅功能检查，不与此前FIFO单DM配置直接比较。CAN3去重反馈计数：0x201=2021、0x10=185、0x13=100（计数包含准备阶段，不代表各电机命令的一一配对）。

UART2：642块/82176字节，HI91有效1001帧，CRC错误0、非有限姿态0、设备时间不推进0、块缺口0。开头66字节用于帧同步，结尾28字节为未完成帧，不能据此认定丢帧。

UART5：86块/1800字节，72个有效SBUS帧，无块序号缺口，72帧均frame_lost/failsafe。用户确认遥控器未开启，因此只判定接收机到主站的数据链路通，不判定遥控状态正常。

见 `run.log`、`rtt.csv`、`uart.csv`、`uart-summary.json`。尚需FIFO正式对照和遥控器开启后的SBUS状态检查。
