# CAN3窗口实验：FIFO40 2000次通过

日期2026-10-30。125us，Rx208/Tx688，CAN3三地址失能/零力矩、UART2 HI91 RX、UART5 SBUS RX；CAN2/IMU排除。FIFO40、mlock1、专用I225 ASPM关闭。固件 `build/periph_can3_window`，默认关闭的 `DUST_ECAT_CAN_FEEDBACK_WINDOW` 由实验配置启用；配套台架按frame sequence去重。

2000命令、2000个顺序配对DM样本通过，timeouts0、WKC_misses0。RTT均值1150.232us，P50 1123.417us，P95 1372.655us，P99 1373.558us，最大1498.354us。这是约20秒的本次负载验证，不是长期稳定性或硬实时证明。之前失败会话只有截断的成功样本，不能用两者均值差宣称优化延迟收益；当前明确收益是本次完整会话没有快照遗漏超时。

CAN3去重反馈：0x201=21337、0x10=3999、0x13=2000，计数包含准备阶段，除DM外不代表每个命令的逐一配对。

UART2：12962块/1659136字节，20232个有效HI91帧，CRC错误0、姿态非有限数0、设备时间不推进0、块序号缺口0、块discontinuity0。首尾同步丢弃76字节及尾部36字节不足一帧，不能据此认定传输丢包。

UART5：1690块/35575字节，1423个结构有效SBUS帧，其中frame_lost4、failsafe0，块序号缺口0、块discontinuity0。frame_lost是收到的SBUS载荷标志，不等于本链路丢掉4个UART块；不能报告为全部遥控帧无异常，也未据此定位无线侧故障。

主站退出后未复位，按窗口版ELF导出RAM，再恢复CPU运行。Mac保存 `build/bench-host/peripheral-can3-window-01/{zephyr.elf,zephyr.hex,.config,...}`，本目录保存原始日志、RTT CSV、UART CSV及离线摘要、末64个主站CAN批次和固件环形记录JSON。当前CAN3 ready1/fault0/errors0，CAN2 ready0。

固件最后512项记录中配对出57个DM映射窗口，中位6122.833us、最大6555.667us、最小635.042us；记录包含停止阶段，最小值不能作为稳态窗口下界。相比失败场景已证明的122us窗口，这支持近期帧保留扩大可见时间的机制解释；不构成每帧必达保证。

当前仍是实验方案，尚未合入主线或修改正式主站。正式 `EthercatSession` 会拒绝跨批次重叠序号，不能混配；滚动淘汰沿用drops计数，还需区分正常窗口淘汰与真正丢失，避免误触发电机解码unwrap复位。后续正式化前，应处理主站去重、能力/模式兼容标识及计数口径，再做回归与更长测试。未改变PDO字段布局。

本轮读取完成后未再次复位，当前主站已释放、网关CPU已恢复运行；后续独立会话前需重新复位。没有安排新的待执行sudo命令。
