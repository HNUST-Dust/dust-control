# DTG1 运行契约

当前通信仅支持 DTG1。125 μs 主站周期交换60字节输出与180字节输入。
IgH 主站、域、PDO注册和所有总线调用均由 EthercatMaster 的同一线程拥有。
配置或协议变化需重启，不热更新、不自动恢复会话。

## 启动与门控

1. 启动前完成 schema 4 应用配置、设备参数、DTG1布局和固定路由校验。
2. 创建各板会话，注册六电机 CAN 来源，启动底盘安全计算。
3. 主站发 Discover，等待匹配非零32位会话 token 的 Ready，再发 Arm。
4. 全部板进入 Active 后发布整机启动许可；实际输出仍受遥控和控制状态机门控。

节点不因 OP 或握手成功自动允许输出。模拟模式不申请主站，也不能允许真实输出。
没有电机业务的板不注册来源；云台/UI目前只有生命周期，不生成虚假心跳。

## 输入

每个电机页只在序号变化时更新反馈时间戳。HI91紧凑页按32位网关序号去重，
支持自然回绕，回退终止会话。异常浮点数或超范围姿态不刷新上一有效样本。
板载 IMU 大端轴值和温度转换为独立快照，不替换 HI91 控制输入。
SBUS整帧页去重并通过Arm记录确认，重传不刷新遥控新鲜度。
当前没有原始UART收发队列、可变容量或通用诊断/状态请求通道。

## 命令与退出

业务提交单周期完整六电机批次，记录单调生成时间和递增来源序号。
缺帧、重复路由、旧序号、未来或过期时间戳均拒绝；来源20 ms未更新即失效。
主站可在有效期内复用同一已编码快照，不能延长业务生成时间或来源有效期。

OP/WKC丢失、Active后重新Ready、从站保护、损坏页和周期停顿超过20 ms均导致整机会话退出。
退出先回收业务线程，再由主站全板发送25次Stop并释放资源；从站本地看门狗是独立保护。
失败后必须重新启动，不在运行中自动Arm。库编译和离线测试不代替固件及实机验收。
