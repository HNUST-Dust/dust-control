# wbr_infantry USB v0.1

首个兵种正式分支版本，源码固定在 `wbr_infantry` 的发布提交。

- 原生 Linux 1 kHz 底盘控制，USB Bulk/CAN 网关通讯。
- 保留原控制算法、参数、符号、零点、使能门控和超时保护。
- 原生 C++ Foxglove 只读遥测：姿态、腿长/竖直距离和运行状态。
- 生产/开发构建隔离，附带离线自动回归和模块化项目结构。
- MPC 与 EtherCAT 为在研模块；本次 production 产物不启用它们。

附件为 Ubuntu 22.04 / Linux x86_64 主机程序，含构建版本信息和 SHA256 校验。
它不是 MCU 固件，也不自动部署或使能机器人。请先阅读包内 README。

验证边界：自动测试覆盖控制契约、USB mock 生命周期、遥测及开发模块回归。
旧版本曾有短时实机控制基线；当前重构发布包未完成新的实机时序验证。
