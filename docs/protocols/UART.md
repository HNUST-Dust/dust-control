# 当前设备输入

DTG1从站负责采集UART5 SBUS和UART2 HI91。主机不配置通用UART容量、用途或写队列。

SBUS由从站以整帧页保留至确认，主机会话检查页格式、去重和序号后交给
WflySbusDecoder；重传触发确认但不刷新遥控采样时间。流中断清除拼帧状态，
无新帧时仍检查遥控超时。

HI91由从站校验并压缩为52字节字段，主机会话显式读取加速度、角速度和姿态。
Hi91Imu只做有限值/姿态范围检查、单位换算、安装轴映射和快照发布；
当前PDO不携带原始串口帧或传感器毫秒时间，主机不重建CRC。

板载IMU使用独立紧凑页，先读取大端三轴加速度和陀螺仪原始值，再由OnboardImu
完成既有量程换算。该样本不替代控制用HI91。

输入模型与控制样本位于设备数据头，传输页定义位于hardware/ethercat。
