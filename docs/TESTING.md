# 构建与测试

```bash
./scripts/test.sh ethercat-ci
./scripts/test.sh headless
```

测试不申请真实主站，不启用电机输出。ethercat-ci默认IgH OFF；ROS可用时增加
遥测语义与真实节点模拟启动/退出测试。headless关闭ROS，启用MPC开发数学回归。

当前合约包括：

- schema生成确定性、字段变更传播、非法结构拒绝。
- DTG1实际映射、固定周期、1～3板聚合和重复地址拒绝。
- schema 4应用配置、设备参数、无效绑定和已移除配置字段拒绝。
- 六电机来源注册、完整批次、生成时间、来源序号和20 ms期限。
- DTG1握手、SBUS重传确认、来源超时后Stop可编码。
- 主站1/3板生命周期、丢线、复位、从站保护、损坏页、周期停顿和统一Stop。
- IMU物理量映射、非法数值、轴值字节序、去重、回绕、回退及快照并发。
- 控制状态机、安全目标、输出握手、观测队列与架构依赖边界。
- `chassis.controller_sequence`：通过公开Tick接口运行有效机构输入，验证使能握手、
  回正完成、安全停止/重使能、倾倒锁存和回正/跳跃/爬楼/腾空失败的下一周期转换。
  可用 `--trace` 输出逐周期状态、电机目标和力矩，用于结构调整前后的行为对照。

`chassis.action_interfaces` 使用左右腿不对称的机构姿态及四关节独立速度，
检查回正/爬楼的具名映射、全部动作阶段、云台约束、完成/超时和复位；
`--trace` 输出阶段、控制许可、云台请求和四关节力矩，供接口调整前后对照。

有真实IgH头文件/库时，可显式开启DUST_BUILD_IGH做生产分支编译。
UnconfiguredHardware测试以零身份拒绝打开设备，不访问实际主站。
可选原MCU平衡数值对照使用DUST_REFERENCE_CHASSIS_DIR；普通构建不依赖外部源码。
离线验证不代表固件完成，也不代替本地保护及实机验收。

`chassis.controller_sequence` 还覆盖跳跃预压缩就绪、200 ms 超时转入推力、
遥控腿长增量屏蔽，以及预压缩中途禁用后的重新使能；通过 `--trace` 可逐周期
对照阶段边界的控制标志和电机输出。

`chassis.balance_sequence` 覆盖左右不对称反馈、变周期更新、运动许可切换、
yaw 跨界、外部支撑力接入/退出，以及复位、使能初始化和参考同步。
零和非零轮力矩预算各运行 3,600 周期，检查输出有限性、关节限幅、
转向分配预算和外部支撑力覆盖；`--trace` 逐周期记录力矩、支撑力、
运动诊断及公开参考状态，用于平衡控制流程调整前后的数值对照。
