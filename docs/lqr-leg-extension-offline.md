# LQR 腿长外推离线评估（2026-11-10）

用户授权先做外推评估。原 CAD 上限 311.01 mm，分析延伸至 340 mm，覆盖
当前悬空读数 335–338 mm。340 mm 仅为分析终点，不代表已确认机械极限。

复现命令：

```sh
OPENBLAS_NUM_THREADS=1 python3 tools/evaluate_lqr_extension.py \
  --output-dir .cache/lqr-extension-340
```

输出 `evaluation.json` 包含输入哈希、外推参数、DARE 残差、稳定性及交叉模型结果。
原 CSV 和运行时增益表不变；不修改实机配置或开启输出。

采用末端 2、3、4 个原 CAD 样本的线性拟合斜率，锚定最后 CAD 样本，
分别外推质心和单腿惯量。保留所有原始数据，新增约 5 mm 间隔节点。
每组在完整范围作 401 点及节点两侧的固定腿长闭环稳定性检查。
另外在外推区间用 101 点检查三组控制器与三组模型的 9 种组合。

| 检查 | 结果 |
| --- | --- |
| 340 mm 质心距轮轴 | 174.09–174.33 mm |
| 340 mm 单腿惯量 | 0.046447–0.046624 kg·m² |
| 三组调度最大离散谱半径 | 0.99830520–0.99830524（均小于 1） |
| 九组交叉检查最坏谱半径 | 0.99830530（均小于 1） |
| 最大相对 DARE 残差 | 2.88e-14 |

340 mm 增益相对本组 311.01 mm 增益的整体 Frobenius 范数变化约 0.62%。
该比例混合不同物理单位，不能作为单个反馈通道变化或鲁棒裕度的指标。
质心值和惯量值在拼接点连续，但质心导数可能跳变，已在调度节点两侧检查。

结论仅为：这些外推模型在小角度、平地双支撑、无饱和的线性假设下可稳定。
不证明真实参数误差已被覆盖，不证明腿长快速变化时的时变系统稳定性，
也不覆盖电机饱和、机构奇异性、氮气弹簧误差、离地、打滑和冲击。
目前高度投影无效也不会由扩大腿长范围自动解决。

实机运行仍使用原模型范围与有效性门控。闭环前需确认机械极限、机构姿态、
高度投影、接触和执行器余量；后续 CAD 数据应替换外推参数。
